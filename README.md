# flask-devops-monolith

A modular Flask monolith built to explore production-oriented DevOps practices: PostgreSQL, Redis, RabbitMQ, background workers, WebSockets, Docker, Nginx, Prometheus, Grafana, and GitHub Actions CI/CD.

```text

flask-devops-monolith/
├── api/
│   ├── requirements.txt
│   └── src/
│       └── app.py
│
├── worker/
│
├── shared/
│
├── tests/
│
├── .gitignore
├── README.md
└── doc.md

```
